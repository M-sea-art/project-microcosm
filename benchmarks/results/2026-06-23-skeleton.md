# Time Compression Benchmark Skeleton

Date: 2026-06-23

This is the first benchmark skeleton for Project Microcosm's
smallest-fastest-path behavior. It is intentionally conservative: it
declares reproducible fixture cases and expected path decisions before
claiming measured productivity gains.

## Cases

- `plan-introduce-forbidden-edge` -> `SPLIT_OR_REVISE_BEFORE_BUILD`
- `plan-add-secondary-writer` -> `SPLIT_OR_REVISE_BEFORE_BUILD`
- `plan-recovery` -> `APPLY_THEN_VERIFY`
- `verify-regression` -> `STOP_AND_MINIMAL_FIX`
- `trust-clean` -> `FAST_TRACK`

## Claim Boundary

This benchmark does not claim wall-clock savings yet. It claims that
Microcosm can convert common slow paths into explicit path decisions
that can be reproduced by tests.
