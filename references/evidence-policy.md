# Evidence Policy

Evidence levels: E4 runtime direct evidence, E3 static direct evidence, E2 documentation evidence, E1 heuristic inference, E0 no-source hypothesis.

Confidence bands: Confirmed >= 0.85; Probable >= 0.60; Concern >= 0.30; Hypothesis < 0.30.

Only Confirmed and Probable findings should enter machine-executable repair queues by default.
