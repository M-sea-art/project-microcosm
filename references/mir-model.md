# MIR Model

MIR means Microcosm Intermediate Representation: one world model with layered evidence.

Top-level keys: meta, project, nodes, edges, assertions, observations, policies, evidence, findings.

Core objects: Node, Edge, Assertion, Observation, Policy, Evidence, Finding. Edge identity is separate from permission; Observation is separate from Assertion; Policy can be allowed, denied, approval-required, or unspecified.
